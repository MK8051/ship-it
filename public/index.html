Cherry-pick, tag, and release tools for Report Builder repos.

Only needed for Release, when sourcing PRs from Linear tasks.
  • Cherry-pick & Tag

    Cherry-pick one or more PRs onto a base tag and push a new tag. Falls back to a downloadable script if a real conflict comes up.

  • Delete Tag

    Permanently delete a tag from the remote repository, with a type-to-confirm safeguard.

  • Rename Tag

    Create a new tag at the same commit as an existing one (preserving annotations), then remove the old one.

  • Release

    Pick your PRs (from Linear or directly), pick where to start from, and pick where they go: a new tag, a new PR, or an existing PR you're adding more to.
